## Model reload investigation

Pinned source: [ComfyUI CLI](https://github.com/Comfy-Org/ComfyUI/blob/426f5eea52a7ece1dd599fff4cb6cd1f352ddd24/comfy/cli_args.py).
`--cache-none` executes every node for each prompt; loaders can therefore be reexecuted. This alone does **not** prove every weight is reread from disk or copied to GPU: ComfyUI model management, OS page cache and device residency also matter. `/free` retains `unload_models=False` by default, while `free_memory=True` can trigger memory management. It is configurable independently of prompt cache.

Per-segment `comfy-segment.log`, `history.json`, `timing.json` and `metrics.json` preserve loader/sampler evidence, total prompt time, generation/postprocess time and GPU memory after cleanup. Separate disk-read, GPU-transfer and sampler durations are **not yet measured**; raw logs may not distinguish those operations. Do not report total time as sampling or loading time.

GPU acceptance remains required: same source/settings/image/seed on L4, fresh RUN_NAME per cache strategy, 3–5s and 6–10s; compare LOW_VRAM False/True; record load/sample timings, memory, seams and `/free` completion. No model-loader caching improvement or L4 speedup is claimed without those runs.

## Rollback

Use `CACHE_STRATEGY='disabled'`, `LOW_VRAM=True`, `VIDEO_ASPECT='16:9'`, `BURN_SUBTITLES=False` for the conservative configuration. `CONFIG['free_memory_between_segments']=False` disables cleanup for diagnosis; `unload_models_between_segments=True` explicitly allows unload. Change generation settings using a new RUN_NAME. To return to original code use commit `688a27c`; never delete model caches as a rollback step.
